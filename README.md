# Cerro Alto · Café de especialidad

Página web de muestras y venta de café de especialidad colombiano.

- Catálogo de cafés con notas de sabor y precios en COP
- Caja de muestras (3 × 50 g)
- Carrito con envío del pedido por WhatsApp
- Un solo archivo HTML, sin dependencias

## Configuración

En `index.html`, cambia la variable `WA` por tu número de WhatsApp con indicativo (ej. `573001234567`) y edita el arreglo `P` con tus cafés y precios.

## Publicar con GitHub Pages

Settings → Pages → Branch: `main` / carpeta `/ (root)`.
